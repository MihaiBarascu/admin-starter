## Project Rules (`multiwebsite-admin-starter`)

- This repo is a reusable starter, not a client-specific app. Keep project-specific domains, D1 IDs, and secrets out of defaults.
- Prefer official documentation and widely used community patterns over custom architecture.
- Worker routing follows Hono best practices:
  - Compose feature modules with `app.route()`.
  - Keep route handlers near route definitions for type inference.
  - Do not create Rails-style controllers unless there is a strong reason.
  - Reusable business logic goes in `service.ts` files.
  - Services receive explicit dependencies like `db` or `env`, not a Hono `Context`.
  - Reusable middleware should use `createMiddleware()` from `hono/factory`.
- Drizzle rules:
  - `src/worker/db/schema.ts` is the schema source of truth.
  - Generate schema migrations with `npm run db:generate`.
  - Do not hand-write normal schema migrations.
  - Keep seed/demo data in explicit seed scripts, not normal generated migrations.
  - Custom SQL migrations are allowed only when Drizzle cannot express the database change.
- Better Auth rules:
  - Mount Better Auth at `/api/auth/*` using the official Hono handler pattern.
  - Keep `AUTH_SIGNUP_ENABLED=false` by default.
  - Use `BOOTSTRAP_ADMIN_TOKEN` only for first-admin creation, then remove or rotate it.
- Testing rules:
  - Current automated tests are API/Worker tests only.
  - Use `npm run test:api` for a one-shot local run.
  - Use `npm run test:api:watch` while developing API changes.
  - API tests must use `@cloudflare/vitest-pool-workers`, not plain Node Vitest, so bindings and D1 run in the Workers runtime.
  - New API routes need tests for unauthenticated access, valid requests, invalid requests, and billable-safety behavior when relevant.
  - Apply D1 migrations in tests through the Cloudflare Vitest D1 helpers; do not hand-create test tables.
- UI rules:
  - Use shadcn/ui components generated by the official CLI.
  - Add primitives with `npm exec shadcn@latest -- add <component>`.
  - Do not invent custom primitives when shadcn has an official component.
- Safety rules:
  - All `/api/*` routes are protected by a 32 KB body limit. Do not increase it unless a route has a documented reason and tests.
  - Unsafe Better Auth requests must require a trusted `Origin`.
  - New public endpoints that can create billable usage must check safety settings before expensive work.
  - Add WAF/rate-limit/deploy notes to `docs/admin-guide.md` when adding billable Cloudflare products.
  - Avoid `console.log` per request. Logs are useful but can become billable at high volume.
